# CS2250 – Fundamentals of Machine Learning Lab

## 📘 Course Information

- **Course Code:** CS2250  
- **Course Name:** Fundamentals of Machine Learning  
- **Programme:** B.Sc (Hons)  
- **Semester:** VI  

## 🎯 Course Objectives

- Provide a foundational understanding of machine learning paradigms.
- Apply supervised learning algorithms for classification and regression.
- Understand neural network architectures and optimization techniques.
- Explore unsupervised learning techniques for high-dimensional data.
- Implement explainable AI methods and deploy ML models using modern frameworks.

---

## 📚 Syllabus Overview

### 🔹 Module 1 – Fundamentals of Machine Learning
- Introduction to Machine Learning
- Types of Learning:
  - Supervised Learning
  - Unsupervised Learning
  - Semi-supervised Learning
  - Reinforcement Learning
- Overfitting vs Underfitting
- Bias-Variance Tradeoff
- Ensemble Learning:
  - Bagging (Random Forest)
  - Boosting (AdaBoost, Gradient Boosting)
  - Stacking
  - Voting Classifiers
- Handling Imbalanced Datasets
- SMOTE (Synthetic Minority Oversampling Technique)
- Feature Engineering and Feature Selection

---

### 🔹 Module 2 – Supervised Learning
- Linear Regression (Simple & Multiple)
- Logistic Regression
- Spline Regression
- Naive Bayes Classifier
- Decision Tree Classifier (ID3 Algorithm)
- Support Vector Machines (Linear & Non-linear)
- Kernel Trick (Polynomial, RBF)
- Sequential Minimal Optimization (SMO)

---

### 🔹 Module 3 – Neural Networks
- Biological Inspiration and Artificial Neurons
- Activation Functions
- Perceptron Model
- Perceptron Learning Rule
- Multi-Layer Perceptrons (MLP)
- Loss Functions
- Backpropagation Algorithm
- Optimization Techniques

---

### 🔹 Module 4 – Unsupervised Learning
- Clustering Algorithms
- K-Means Clustering
- DBSCAN
- HDBSCAN
- Spectral Clustering
- Dimensionality Reduction
- t-SNE
- UMAP

---

### 🔹 Module 5 – Reinforcement Learning & ML Deployment
- Basics of Reinforcement Learning:
  - Agents
  - Environment
  - Rewards
  - Policy
  - Value Functions
- Introduction to Deep Q-Networks (DQN)
- Explainable AI (XAI)
  - Interpretable Models
  - LIME
  - SHAP
- Deployment using:
  - Flask
  - Streamlit
  - FastAPI
- Future Trends:
  - Foundation Models
  - Multimodal Learning

---
